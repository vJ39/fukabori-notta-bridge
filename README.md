# fukabori-notta-bridge

fukabori.fmのエピソード音声をダウンロードし、Nottaへ自動アップロードして文字起こしを開始するChrome拡張機能。

## インストール(開発版)

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」からこのリポジトリのルートを選択

## 使い方

1. Nottaに事前にログインしておく
2. fukabori.fmのエピソードページを開く
3. 右下に表示される「Nottaで文字起こし」ボタンを押す
4. 音声がダウンロードされ、Nottaのタブが開いて自動でアップロードが始まる

## テスト

純粋ロジック(ファイル名サニタイズ)のみNode組み込みのテストランナーでテストしている。DOM操作部分は対象外。

```
npm test
```

## 現状の制約

詳細は [docs/spec.md](docs/spec.md) を参照。Nottaのアップロード欄のセレクタは実機未検証のため、動かない場合は調整が必要。動かない場合のログの見方も spec.md の「デバッグ方法」を参照。
